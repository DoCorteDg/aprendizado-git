#Boas práticas de Git e GitHub

## 1 - Faça commits descritivos 
Utilize mensagens que expliquem as alterações realizadas.

## 2 - Utilize branches
Crie branches separadas para novas funcionalidades e correções.

## 3 - Revise as alterções 
Analise o conteúdo de um Pull Request antes de integrar as mudanças a branch principal.

## 4 - Projeta informções sensíveis
Nunca envie senhas, tokens ou chaves privadas para um repositório público
